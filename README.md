# Dialogflow CX Pizza Ordering Agent

## Overview
This project is a conversational AI agent built using Google Dialogflow CX that simulates a full pizza ordering and checkout experience through text-based interaction. The agent guides users through selecting a signature or custom pizza, adding drinks and sides, reviewing their order, correcting details if needed, and completing checkout.

The focus of this project is conversational flow design, state management, and natural language interaction rather than real-world payment processing or pricing logic.

## Project Context
This project was developed as part of a graduate-level Applied Natural Language Processing course. While the original assignment was completed in a group setting, I was responsible for designing and implementing the conversational agent itself, including flow architecture, page routing, intent handling, and dialog logic within Dialogflow CX.

This repository presents the system as a standalone portfolio case study, consolidating the technical design, implementation details, and testing outcomes into a single, curated format.
